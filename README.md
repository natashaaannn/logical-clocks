# logical-clocks

# Логическое время в распределенных системах

Программа на C++ для симуляции работы логических часов в распределенной системе из 3 процессов.

### Что реализовано в коде:
* **а) Сравнение на основе счетчика событий (Скалярное время).
* **б) Векторные часы. Реализован динамический массив `std::vector<int>` для отслеживания причинно-следственных связей.
* **в) Проверка отношения порядка (e ≤ e'). Реализована функция `isLessOrEqual` для математического доказательства того, что одно событие гарантированно предшествовало другому.
